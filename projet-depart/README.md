# Le Labo du quartier
Dans ce dossier, ouvrir un terminal (Node.js 22.12+ et npm).
```sh
npm ci
npm start
```
Ouvrir http://localhost:4173/ dans Chrome. Laisser ce terminal ouvert.
Après les modifications, lancer `npm run actualiser` dans un deuxième terminal, depuis le même dossier. Attendre la fin puis recharger la page.
Le domaine fictif https://labo.example sert uniquement à écrire les URL canoniques et le sitemap. Les tests de la séance se font sur localhost.
